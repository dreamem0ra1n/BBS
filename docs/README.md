# 开发文档

这里存放供项目开发者和 agent 直接阅读的 Markdown 文档。在编辑器或代码托管平台中打开即可，无需安装依赖、启动服务或构建文档站。

## 阅读入口

| 需要了解什么 | 阅读文档 |
| --- | --- |
| 项目组成、环境准备、本地运行和服务器部署 | [仓库 README](../README.md) |
| 从哪里查找代码、如何核对实现与维护文档 | [开发指南](development.md) |
| API 地址、认证、请求编码、响应格式与调用示例 | [接口公共约定](api/README.md) |
| 登录、用户、帖子、评论、搜索、上传等接口 | [Web 接口](api/site.md) |
| 用户与内容管理、配置和维护接口 | [管理后台接口](api/admin.md) |
| 后端构建与密码登录的编译条件 | [后端 README](../server/README.md) |
| 数据库初始化 | [建库与建表说明](../server/initDB.md)，配合仓库 README 使用 |

```text
    ├── site.md         Web 接口

```

## 给开发者和 agent 的阅读顺序

1. 首次接触项目时，先读仓库 README 和开发指南，确认现有组件与运行方式。
2. 对接接口时，先读接口公共约定，再按任务查看 Web 或管理后台接口，并核对对应源码。
3. 涉及前端迁移时，如果工作区存在 `FRONTEND_REFACTOR.md`，先读该计划，区分现有实现、计划与已验证结果。该计划单独维护，不属于本目录的必需文件。

新增说明按主题放入本目录，并在本页添加入口。运行和部署命令统一维护在仓库 README；接口行为统一维护在 `api/`，避免多处复制后出现差异。
